What can I upload?

Upload one ZIP with class folders, optional train/validation/test folders, or images in multiple folders paired with CSV/JSON metadata. DermaAudit automatically maps image IDs to labels such as HAM10000's image_id → dx. JPG, PNG, WEBP, BMP, GIF, JFIF, and TIFF are supported.

UPLOAD GUIDE / STEP BY STEP

Upload your original dataset structure

Keep the dataset structure unchanged, then compress the complete folder into one .zip file before uploading. You do not need to move images into new class folders—DermaAudit detects class folders, image-part folders, and CSV/JSON metadata such as HAM10000 automatically.

Flexible formats
01

Best option: classes inside train and test

The class name should be the folder directly above each image.

my_dataset/
├── train/
│   ├── class_a/
│   │   ├── image_001.jpg
│   │   └── image_002.png
│   └── class_b/
│       ├── image_003.jpg
│       └── image_004.png
├── validation/
│   ├── class_a/
│   │   └── image_005.jpg
│   └── class_b/
│       └── image_006.jpg
└── test/
    ├── class_a/
    │   └── image_007.jpg
    └── class_b/
        └── image_008.jpg

Important: Replace class_a and class_b with your real labels. train, validation, and test are split folders—not classes. At least two classes are required.

02

Simple option: no split folders

Use this when you want DermaAudit to inspect one labeled image collection.

my_dataset/
├── cats/
│   ├── cat_001.jpg
│   └── cat_002.webp
├── dogs/
│   ├── dog_001.jpg
│   └── dog_002.png
└── rabbits/
    └── rabbit_001.tiff

Every image must be inside a class folder. Files placed directly in my_dataset/ do not have a reliable label unless a manifest maps each filename to a class.

03

Alternative: flat images + metadata

Use CSV or JSON when labels are stored in a spreadsheet instead of folders.

my_dataset/
├── images/
│   ├── img_001.jpg
│   └── img_002.png
└── labels.csv
labels.csvfilename,label,group_id images/img_001.jpg,cat,subject_01 images/img_002.png,dog,subject_02

Use a filename/image/path column and a label/class/category/target column. group_id or patient_id helps detect data leakage.

04

Medical option: HAM10000-style folders

Keep multiple image-part folders and let metadata provide the labels.

HAM10000/
├── HAM10000_images_part_1/
│   └── ISIC_0024306.jpg
├── HAM10000_images_part_2/
│   └── ISIC_0030000.jpg
├── HAM10000_metadata.csv
└── hmnist_28_28_L.csv
HAM10000_metadata.csvimage_id,dx ISIC_0024306,mel ISIC_0030000,nv

The image-part folders are treated as containers, not classes. image_id maps to the image filename and dx becomes the class label. Additional hmnist_*.csv files are detected and marked unused when original JPEGs are available.

05

Before you create the ZIP

Quick checklist to avoid validation errors.

  • ✓

    Use real labels. Folder names or metadata values become prediction classes.

  • ✓

    Keep images readable. Minimum image dimension is 32×32 pixels.

  • ✓

    Use supported raster files. JPG, JPEG, JFIF, PNG, WEBP, BMP, GIF, TIF, or TIFF.

  • ✓

    Keep useful metadata. CSV/JSON label files are mapped; extra tabular exports are detected and marked unused, not silently deleted.

  • ✓

    Remove unrelated files. A README is fine, but nested ZIPs and unsupported documents are skipped.

ⓘ

What does not work? A ZIP containing only loose images, a ZIP with just one class, a non-ZIP upload, or an image folder with no labels. Corrupted, duplicate, low-resolution, and unlabelled images are removed automatically by cleaning — but an archive where more than 25% of the images are unreadable stays in review. The audit page shows the exact files, severity, and recommended actions.
