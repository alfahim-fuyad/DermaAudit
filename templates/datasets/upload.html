What can I upload?

Upload one ZIP with class folders, optional train/validation/test folders, or flat images paired with a CSV/JSON manifest. JPG, PNG, WEBP, BMP, GIF, JFIF, and TIFF are supported. A manifest must include an image filename/path and a label/class column.

UPLOAD GUIDE / STEP BY STEP

Prepare your folder correctly

Keep the original folder on your computer, then compress it as a single .zip file before uploading. Do not upload an uncompressed folder.

Recommended format
01

Best option: classes inside train and test

The class name should be the folder directly above each image.

my_dataset/
├── train/
│   ├── class_a/
│   │   ├── image_001.jpg
│   │   └── image_002.png
│   └── class_b/
│       ├── image_003.jpg
│       └── image_004.png
├── validation/
│   ├── class_a/
│   │   └── image_005.jpg
│   └── class_b/
│       └── image_006.jpg
└── test/
    ├── class_a/
    │   └── image_007.jpg
    └── class_b/
        └── image_008.jpg

Important: Replace class_a and class_b with your real labels. train, validation, and test are split folders—not classes. At least two classes are required.

02

Simple option: no split folders

Use this when you want DermaAudit to inspect one labeled image collection.

my_dataset/
├── cats/
│   ├── cat_001.jpg
│   └── cat_002.webp
├── dogs/
│   ├── dog_001.jpg
│   └── dog_002.png
└── rabbits/
    └── rabbit_001.tiff

Every image must be inside a class folder. Files placed directly in my_dataset/ do not have a reliable label unless a manifest maps each filename to a class.

03

Alternative: flat images + metadata

Use CSV or JSON when labels are stored in a spreadsheet instead of folders.

my_dataset/
├── images/
│   ├── img_001.jpg
│   └── img_002.png
└── labels.csv
labels.csvfilename,label,group_id images/img_001.jpg,cat,subject_01 images/img_002.png,dog,subject_02

Use a filename/image/path column and a label/class/category/target column. group_id or patient_id helps detect data leakage.

04

Before you create the ZIP

Quick checklist to avoid validation errors.

  • ✓

    Use real labels. Folder names or metadata values become prediction classes.

  • ✓

    Keep images readable. Minimum image dimension is 32×32 pixels.

  • ✓

    Use supported raster files. JPG, JPEG, JFIF, PNG, WEBP, BMP, GIF, TIF, or TIFF.

  • ✓

    Remove unrelated files. A README is fine, but nested ZIPs and unsupported documents are skipped.

ⓘ

What does not work? A ZIP containing only loose images, a ZIP with just one class, a non-ZIP upload, corrupted images, or an image folder with no labels. The profile page will show the exact files and warnings to fix.
